# Gullgraveren: Dypet

## ▶ [SPILL HER: jsr-semy.github.io/Gold-digger-3D](https://jsr-semy.github.io/Gold-digger-3D/?v=2)

Et førstepersons gruvespill for Meta Quest 3 (WebXR), inspirert av klassiske gull-og-troll-plattformspill.

Gulvet i stua åpner seg, og du faller ned i en gruve full av gull og troll. Samle alt gullet på hvert nivå, finn hullet i nederste etasje og fall videre. Først etter siste nivå kommer du opp igjen.

**Spill:** åpne GitHub Pages-adressen til dette repoet i nettleseren på Quest 3.

- To bevegelsesmoduser: styrespak (glatt) og teleport
- Klatring i stiger med grepknappen, hånd over hånd
- Radar på venstre håndledd: troll (rødt), gull (gult), utgang (grønt)
- TV-modus med Xbox-kontroll (fullskjerm, stor radar)
- PC-modus for testing: WASD, mus, mellomrom/C for å klatre

Alt ligger i `index.html` (Three.js fra CDN, ingen byggesteg).
